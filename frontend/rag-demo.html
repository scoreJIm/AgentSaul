什么是 RAG？

Retrieval-Augmented Generation 将用户问题先用来检索相关文档，再把这些文档作为"上下文"注入到 Prompt 中，让 LLM 基于检索到的知识来回答——而不是仅凭训练记忆。

Prompt Engineering 要点：
1. 分块策略影响检索精度
2. Prompt 模板决定 LLM 如何使用检索结果
3. Top-K平衡召回率和准确率
4. 相似度阈值过滤不相关内容
