什么是 MCP?

Model Context Protocol 是 Anthropic 提出的开放协议，标准化了 AI 应用与外部工具/数据源之间的通信方式。

核心概念：
1. Tool Discovery — Client 连接 Server 后自动发现可用工具
2. Tool Invocation — LLM 决定调用工具 → Client 通过 MCP 发送请求 → Server 执行并返回
3. 标准化 Schema — 每个工具都有 JSON Schema 描述参数
4. 传输层抽象 — 支持 SSE/STDIO/Streamable HTTP

vs 直接 @Tool

传统方式：@Tool 注解直接注入 ChatClient，LLM → 本地方法调用

MCP 方式：@Tool → MCP Server 暴露 → MCP Client 发现 → LLM 调用

优势：工具提供者和消费者解耦，不同语言/进程/网络位置的工具可以统一管理
